# dws‑cli工具
- **CLI**：命令行界面，通过终端输入文本命令执行操作，无需图形鼠标，便于脚本自动化执行。
- **dws‑cli**：DWS数仓的命令行客户端工具，部署在Ubuntu虚拟机，用于执行SQL查询，将数仓数据导出为CSV文件，作为后续任务原始数据源。

**使用方式**
1. 环境校验：虚拟机终端执行 `dws-cli --help`，验证工具正常可用。
2. 执行查询导出CSV：
```bash
dws-cli query --sql "select 姓名,所属单位,\"职务或角色\",个人简介 from 表名 where \"职务或角色\"='兼职导师';" --output ./part_time_tutors.csv
```
3. 导出得到`part_time_tutors.csv`，供给后续Python脚本做数据孵化处理。
